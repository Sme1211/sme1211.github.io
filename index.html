Privacy Policy

Proxmox Backup is a personal, self-hosted backup application operated exclusively by its owner.

Google Drive access

The application uses OAuth 2.0 with the Google Drive drive.file scope to access files created or authorized for the application.

Data usage

Google Drive access is used exclusively to upload, verify, retrieve and manage the owner's encrypted backups.

Data storage

Backup files are encrypted locally using Rclone Crypt before being uploaded to Google Drive. OAuth credentials are stored on the owner's private server.

Data sharing

The application does not sell user data or share backup contents with advertisers.

Access revocation

The owner can revoke access through Google Account security settings.
